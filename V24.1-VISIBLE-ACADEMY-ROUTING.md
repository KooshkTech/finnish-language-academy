# V24.1 — Visible Academy Routing

The V24 academy foundation originally lived under `/learn/academy`, so existing `/courses/*` pages still rendered the older course UI.

V24.1 makes the new academy visibly primary:

- `/courses` redirects to `/learn/academy`
- legacy course URLs redirect into the matching OPIOPE Academy book
- `/learn` hero now promotes OPIOPE Academy directly
- old URLs remain safe instead of becoming broken links

Mapping:

- fi-a0 -> OPIOPE 1
- fi-a1 -> OPIOPE 1
- fi-a2 -> OPIOPE 2
- fi-b1 -> OPIOPE 3
- fi-b2 -> OPIOPE 4
- fi-c1 -> OPIOPE 5
- fi-c2 -> OPIOPE 6
