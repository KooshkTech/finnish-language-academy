# OpiOpe V24.4 — Course-first account flow

## Implemented

- Landing page now begins with two course choices only: Suomi and Ruotsi.
- Each language has its own A0–C2 level hub.
- After choosing a course, users choose Opiskelija/Studerande, Opettaja/Lärare, or Vapaa/Fri user.
- All three account types have sign-in UI and account creation links.
- Registered free users are represented as `role=student` plus `account_mode=free`; this preserves server authorization while keeping the product mode distinct.
- Teacher account creation is an application/pending workflow. A browser cannot grant itself teacher privileges.
- Profiles store `course_language` (`fi` or `sv`) and `account_mode`.
- Added migration `20260912010000_course_first_accounts.sql`.
- Role login now routes registered free users back to their chosen course level hub.
- Student dashboard now uses the account's selected course language.
- Finnish Academy lesson player no longer displays English vocabulary translations or English UI headings such as DISCOVER/EXPLAIN/ROLEPLAY.

## Required database step

Apply Supabase migrations before testing account creation and sign-in.
