# OpiOpe V22.2 — Interactive Q&A Engine

## Implemented
- Shared interactive Q&A loop for speaking, listening, reading, writing, understanding and Voice Lab.
- A0–C2 level selection on standalone skill routes.
- Voice-first recording for speaking/Voice Lab and voice-or-text for listening/reading/understanding.
- Browser TTS with 0.5x / 0.75x / 1.0x playback controls.
- Existing secure STT route used for microphone transcription.
- New `/api/qa/evaluate` endpoint with rate limiting.
- Provider-backed detailed text evaluation when `OPENAI_API_KEY` is configured.
- Deterministic key-point fallback when AI is unavailable; it explicitly does not pretend to be a full grammar or pronunciation assessment.
- Structured feedback compatible with `QAEvaluationResponse`.
- Blackboard synchronization via the existing `opiope:blackboard-note` event.
- Kirjakieli / puhekieli model answers.
- OpiOpe Advanced Dictionary deep-links (no Oxford affiliation claim).
- Local device review/SRS queue for selected words.
- Listening stimulus playback + optional transcript reveal after listening.
- Reading passages, writing prompts and level-aware question loops.

## Deliberately not faked
- No phoneme/pitch score from transcript text.
- No "native speaker" score.
- No official CEFR/YKI score.
- No Oxford dictionary/license claim.
- No claim that local SRS queue is cloud-synced when the learner is not authenticated.

## Production configuration
- `OPENAI_API_KEY` enables AI text evaluation and existing STT.
- Optional `OPENAI_QA_MODEL`; falls back to `OPENAI_TUTOR_MODEL`, then `gpt-5.6-luna`.
- A dedicated acoustic pronunciation adapter can be added later; until then pronunciation status remains truthful and non-numeric.
