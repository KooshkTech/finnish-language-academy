# OpiOpe V15 Classroom Engine

## Implemented foundation
- Dedicated routes for listening, reading, writing, speaking, understanding, vocabulary, YKI practice and AI tutor.
- Shared four-tab blueprint: Learn, Practice, Flashcards, Test & Assessment.
- Reusable Blackboard renderer for notes, comparisons and tables.
- Browser-local speaking recorder with truthful no-scoring state.
- Weekly schedule template and persistent Supabase schema for assignments/accountability.
- AI tutor API route with secure server-only configuration gate. Live provider execution remains disabled until rate limits, retention, moderation and privacy configuration are verified.

## Not yet production-complete
- Real audio library/transcripts and synchronized playback.
- Speech scoring/accent evaluation.
- Full SM-2 persistence for every topic-specific flashcard.
- Adaptive weekly scheduler job and 23:59 deadline worker.
- Server-authoritative reward/penalty transaction logic.
- Official YKI scoring (must never be claimed).
- Live AI provider integration and Blackboard JSON streaming.

These must be implemented and tested before being marketed as live features.
