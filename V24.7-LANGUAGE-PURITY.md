# OpiOpe V24.7 — Finnish course language purity

This release makes the Finnish A0–C2 classroom native-first instead of translation-first.

- Finnish lesson examples no longer render English glosses by default.
- Flashcard backs use native dictionary definitions when available.
- Practice and assessment questions are generated in Finnish rather than using English translation answers.
- Blackboard uses Finnish explanation/notes instead of English target text.
- Advanced Dictionary hides English definitions and collocation translations in the default learner UI.
- Q&A model metadata no longer injects English translations into the learner flow.
- Added `npm run audit:course-language`.

The original English translation fields may remain in seed data as internal legacy metadata, but the Finnish learner UI no longer depends on them. Swedish lesson content remains a separate course and must be expanded independently.
