# V24.22.1 GitHub integration

Integrated onto the existing academy main branch without deleting its original curriculum, lesson shell, homepage, practice, tutor, progress, or YKI pages.

- Added teacher/student workspaces, calendar, live sessions, attendance, notifications, community feed, assignments, and course-language/account flows.
- Added the V24.22.1 redirect, attendance, CSV, reaction, and side-effect fixes.
- Preserved existing UI dependencies and scoped the release styles beneath `.v24-release`.
- Added `/gateway` and visible academy links for Finnish/Swedish registration and login.
- Upgraded `/review` to the real review center; the original academy review is retained at `/review/academy`.
- Standardized installs on npm with `package-lock.json`; removed the obsolete pnpm lockfile to avoid frozen-lockfile deployment conflicts.
- Added GitHub Actions release validation using Node 24.

Run `npm ci` and `npm run verify:release`. The gate includes lint, typecheck, tests, build, class-sessions audit, community audit, and all subsequent feature audits.

Before live-account testing, configure `.env.local` from `.env.example` and apply the included Supabase migrations in chronological order. No production database was modified during this integration. Live-account, MFA, RLS, and meeting-link testing still require a configured staging project.
