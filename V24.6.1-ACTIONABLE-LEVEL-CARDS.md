# OpiOpe V24.6.1 — Actionable level cards

Fixes the A0–C2 course level pages where Kuuntelu/Lukeminen/Kirjoittaminen/Puhuminen/Kielioppi/Sanasto (and Swedish equivalents) were static `<article>` elements.

## Changes
- Each skill card is now a keyboard-accessible Next.js `Link`.
- Finnish skill cards open the existing full classroom engine at `/levels/{level}/{skill}`.
- `Kielioppi` maps to the existing `understanding` classroom module.
- Swedish skill cards open a Swedish-only activity hub rather than leaking Finnish classroom content.
- Added hover/focus states and an arrow affordance so cards visibly behave like actions.
- Preserves Suomi/Ruotsi separation.

## Validation
Run:

```bash
npm install
npm run lint
npm run typecheck
npm run build
npm run dev
```

Then verify `/course/fi/levels/a1`: every card must be clickable and open a real destination.
