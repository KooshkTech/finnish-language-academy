# OpiOpe V22 — Learning Content Release

## Goal
Move OpiOpe from a technically healthy prototype with only a few course lessons to a credible pre-launch learning product.

## Added course depth
- A0: 15 published lessons
- A1: 20 published lessons
- A2: 22 published lessons
- B1: 30 published lessons
- Total: 87 published structured lessons before B2–C2

Every generated course lesson contains:
- Learn stage
- Understand stage
- Practice stage
- Apply stage
- Check stage
- 6 assessed exercises
- vocabulary checks
- grammar focus
- model sentence
- translation/writing task

This yields 522 assessed exercise items across the published A0–B1 course path.

## Curriculum focus
A0: greetings, numbers, time, family, home, food, shopping, transport, weather, help phrases.

A1: daily routines, local cases, shopping, café/restaurant, housing, family, work, phone, messages, appointments, questions, partitive, spoken Finnish.

A2: imperfect/perfect, experiences, workplace communication, shifts, email, housing problems, banking, post, authorities, health, phone calls, object, rections, connectors, comparison, spoken Finnish.

B1: complaints, authorities, work meetings, task clarification, feedback, interviews, contracts, absence, opinions, disagreement, comparison, negotiation, email, news, summaries, instructions, sources, perfect, passive, conditional, if-clauses, connectors, YKI intermediate practice strategies.

## Truthful launch positioning
- A0–B1: available as structured course content.
- B2–C2: still marked as expanding/development.
- OpiOpe YKI content remains practice only, not an official YKI test or certificate.

## UX improvement
`/learn` now contains a clear “Jatka oppimista” section that shows the published A0–B1 courses and lesson counts, reducing the need for learners to hunt through tools.

## Still recommended before public launch
- Real account-backed progress persistence and resume state.
- More real listening audio / TTS integration in course lessons.
- Speaking recorder integrated into course lesson flow.
- Student registration, email verification, password reset.
- Teacher upload → draft → review → assign flow end-to-end on production Supabase.
- RLS tests with two student accounts and one teacher account.
- Mobile and accessibility QA.
- B2–C2 expansion after A0–B1 learner testing.
