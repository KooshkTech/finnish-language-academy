# OpiOpe V24.9 — Student Progress & Lesson Completion

## Added
- Persistent lesson progress for both Finnish (`fi`) and Swedish (`sv`) course routes.
- Every classroom records a course-aware lesson key such as `fi:a1:reading` or `sv:b1:speaking`.
- Signed-in learners save progress to the existing Supabase `lesson_progress`, `user_progress`, `daily_activity`, and `exercise_attempts` tables.
- Free/unsigned users fall back to the existing local guest-learning store on the device.
- Lesson start is recorded, tests raise lesson progress, and learners can explicitly mark a lesson complete.
- Finnish and Swedish test attempts are persisted for signed-in learners and kept locally for guest learners.
- Student dashboard now shows recent lessons, completion state, progress percentage, and links back to each lesson.
- "Continue learning" now resumes the saved current lesson when available.

## No new database migration required
This version reuses the existing V7 learning tables and RLS policies. The lesson slug carries language, level, and skill, which avoids a schema migration for this phase.

## Manual QA
1. Sign in as a student.
2. Open a Finnish lesson, complete its test, mark it complete, then open `/student` and verify the progress row and resume link.
3. Repeat with a Swedish student and a Swedish lesson.
4. Sign out and confirm free-user progress is retained locally on the same device.
5. Confirm one student's dashboard does not expose another student's data.
