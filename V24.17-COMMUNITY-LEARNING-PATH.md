# OpiOpe V24.17 — Community Feed + Learning Path

This release adds a private class feed with pinned teacher posts, safe internal links, student comments, one-click reactions, and in-app notifications. The student class view now combines the feed with CEFR level, XP, streak, Kulta balance, and editable weekly minute/lesson goals.

## Deployment

Apply `supabase/migrations/20260915120000_class_feed_learning_path.sql` before testing real accounts. New public tables use RLS and explicit Data API grants; mutations run through authenticated server routes.

## Validation

```bash
npm install
npm run verify:release
```

`verify:release` is the mandatory release gate. It runs lint, TypeScript,
the production build, the class-session audit, and the community audit in
order. Do not package a future OpiOpe version unless this command passes.
