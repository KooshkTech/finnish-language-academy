# OpiOpe V24.13 — Teacher Analytics & Student Performance

This release adds teacher-facing analytics without introducing a new database migration. It calculates analytics from existing class membership, lesson progress, exercise attempts, daily activity, assignments, and assignment submissions.

## Added

- Class analytics route: `/teacher/classes/[classId]/analytics`
- Class-level average lesson progress
- Exercise accuracy
- Assignment score average
- 14-day learning activity
- Weakest skill areas based on exercise attempts
- Students-needing-attention detection
- Missing and overdue assignment signals
- Per-student performance table
- Expanded individual student performance dashboard
- Finnish and Swedish teacher labels
- `npm run audit:teacher-analytics`

## Attention rules

A student is highlighted when one or more of these conditions is true:
- no recent learning activity for at least 7 days
- at least 5 recent exercise attempts with accuracy below 60%
- one or more overdue class assignments have not been submitted
- several lesson-progress records exist but average progress is below 40%

These signals are teacher decision support only. They are not automated grades or diagnostic claims.

## Database

No migration is required for V24.13. Existing tables are reused:
- `teacher_class_members`
- `profiles`
- `lesson_progress`
- `exercise_attempts`
- `daily_activity`
- `teacher_assignments`
- `assignment_submissions`
