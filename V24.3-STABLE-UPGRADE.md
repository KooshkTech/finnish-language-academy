# OpiOpe V24.3 Stable Upgrade

Base: V24.1 Visible Academy.

## Added in this upgrade
- Protected student dashboard at `/student`.
- Student login/registration redirects to `/student`.
- Separate teacher class workspace at `/teacher/classes`.
- Teacher class detail with authorized class members only.
- Teacher student detail page with lesson progress and recent learning difficulties.
- Existing teacher dashboard now links clearly to class/student management and AI-assisted lesson drafting.
- Central browser speech helper that selects only Finnish (`fi-*`) or Swedish (`sv-*`) voices and never falls back to an English voice.
- Key listening/Q&A UI strings changed from English to Finnish/Swedish.
- Integration curriculum foundation: `Suomi arkeen ja kotoutumiseen` / `Finska för vardag och integration` with 20 practical modules.
- Supabase migration for UI/target language, current level, learning goal, class type, recurring lesson plans, lesson versioning, and teacher-authorized student analytics.
- Recurring lesson frequencies supported by schema: manual, daily, weekly, monthly, yearly.
- Teacher approval remains required by default for recurring AI lesson plans.

## Existing V24.1 functionality preserved
The existing Next.js 16 / React 19 architecture, Academy routes, teacher content studio, Supabase auth, teacher MFA/access checks, daily lesson CMS, class join flow, privacy/GDPR controls and current course engine remain in place.

## Production configuration still required
- Apply Supabase migrations to a test/staging project before production.
- Configure `OPENAI_API_KEY` and `OPIOPE_AI_MODEL` for AI lesson drafts.
- Keep `SUPABASE_SERVICE_ROLE_KEY` server-only.
- Run the project validation commands locally before merging or deploying.
