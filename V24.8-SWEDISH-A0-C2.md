# OpiOpe V24.8 — Swedish A0–C2 course foundation

This release replaces the Swedish placeholder action pages with a real Swedish classroom path for every level A0–C2 and these six skills:

- Lyssna
- Läsa
- Skriva
- Tala
- Grammatik
- Ordförråd

Each level/skill now has Swedish-only goals, examples, vocabulary definitions, practice questions, flashcards, a small test, and Blackboard material. Finnish course routing remains unchanged.

This is a structured first Swedish lesson bank, not a claim that the complete pedagogical curriculum is finished. More lessons per skill/level still need to be authored before a full commercial launch.
