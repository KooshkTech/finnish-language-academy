# OpiOpe V24.14 — Class creation, join-code onboarding and roster management

## Added
- Teacher class creation directly on `/teacher/classes`.
- Course language is inherited from the authenticated teacher (`fi` or `sv`).
- Copyable join code and join-code rotation.
- Student join page localized to the student's course language.
- Successful join returns the learner to `/student`.
- Teacher roster controls for removing a learner from a class.
- Teacher roster controls for moving a learner to another class owned by the same teacher and in the same course language.
- Server-side ownership and course-language checks for all roster mutations.
- Audit-log events for class creation, join-code rotation, removal, and move operations.

## Database
No new migration is required. V24.14 uses the existing `teacher_classes`, `teacher_class_members`, `profiles`, and `security_audit_log` tables.
