# OpiOpe V21.1 — Teacher Auto-Lesson + Legal/Security/SEO Audit

## Implemented in this revision

### Teacher workflow
- Added `/teacher` dashboard.
- Added `/teacher/content-studio` behind approved-teacher + MFA (AAL2) checks.
- Teacher can upload TXT/MD/PDF/image/audio or paste source text.
- Upload requires an explicit rights confirmation.
- Files are stored in a private teacher-material bucket with UUID object names.
- TXT/MD can become lesson drafts immediately when AI is configured.
- PDF/image/audio are safely stored and wait for a configured OCR/STT processor unless source text is pasted.
- AI generation uses server-side OpenAI Responses API + Structured Outputs when `OPENAI_API_KEY` and `OPIOPE_AI_MODEL` are configured.
- Generated output contains lesson theory/examples, vocabulary, grammar, Blackboard blocks, varied practice, flashcards, test questions, teacher notes, and limitations.
- Generated content is always `review-required`; automatic publication is intentionally forbidden.

### Security
- Teacher remains invitation-only and server-role verified.
- Teacher workspace requires MFA by default.
- Teacher content generation is rate limited.
- Service-role keys remain server-only.
- Uploads use MIME allowlists, file-size limits, file-signature checks and private storage.
- No SVG/HTML/executable upload types are accepted.
- Supabase/provider raw errors are not returned by the learner profile API.
- Kids cloud profile sync is blocked until a guardian/organization consent workflow exists.
- Youth account sync requires a 13+ confirmation in the current consumer workflow.
- Teacher/account/admin routes are not search-index targets.

### Legal/trust
- Privacy policy now includes children/youth, teacher-upload processing and AI transparency sections.
- Terms now include teacher copyright responsibility and mandatory human review of AI-generated teaching drafts.
- User-facing Oxford naming was removed in favor of `OpiOpe Advanced Dictionary` to avoid implying third-party branding/data affiliation.
- AI must not be used for emotion recognition in education.
- Practice assessment remains non-official and does not claim YKI/CEFR certification.

### SEO
- Added explicit metadata/canonical for `/` and `/learn`.
- Added dynamic unique metadata/canonical for every A0–C2 level page and level-skill page.
- Expanded sitemap to public A0–C2 level/skill routes.
- Added conservative `WebSite` + `SoftwareApplication` JSON-LD on the public root.
- Did not add Google `Course` rich-result markup because it should only be used when the actual course offering meets Google's current eligibility requirements.
