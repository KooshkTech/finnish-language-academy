# OpiOpe V24.10 — Mistakes, Review & SRS

## Added
- A working `/review` center for Finnish and Swedish.
- Language-aware SRS vocabulary queues.
- “Add to review” buttons on Finnish and Swedish flashcards.
- SM-2-inspired scheduling already present in `services/vocabulary.ts` is now wired to real UI.
- Signed-in learners persist review state to Supabase; anonymous/free local learners keep review state in localStorage.
- Wrong test attempts now store learning language, question text and correct answer for useful mistake review.
- Recent mistakes link back to the source lesson.
- New Supabase migration `20260914060000_review_srs_language.sql` makes vocabulary uniqueness language-aware and enriches exercise history.
- New `npm run audit:review-srs` static QA check.

## Important deployment step
Apply the new Supabase migration before testing signed-in SRS/review. Local/anonymous review works without it.

## Validation target
Run:

```bash
npm install
npm run lint
npm run typecheck
npm run build
npm run audit:language
npm run audit:course-language
npm run audit:swedish-course
npm run audit:student-progress
npm run audit:review-srs
```
