# OpiOpe V24.15 — Class communication

Adds secure class invitations, class announcements, and teacher/student direct messaging on top of V24.14.

## Included
- Shareable class invitations with random expiring tokens.
- Optional targeted invitation by student username.
- Student invitation acceptance with course-language and target-account checks.
- Teacher class announcements with in-app notifications to all class members.
- Teacher ↔ student direct messages restricted to active class membership.
- Student class page for announcements and messaging.
- Teacher per-student message page.
- Security audit events and rate limits.

## Database
Apply `supabase/migrations/20260914123000_class_communication.sql` before using the new features with real accounts.

## Validation
Run `npm run audit:class-communication`, then lint, typecheck and build.
