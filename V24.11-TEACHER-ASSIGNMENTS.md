# OpiOpe V24.11 — Teacher assignments, submissions and feedback

This release connects the teacher-class workflow to real homework delivery.

## Added
- Teacher can create a class assignment with title, CEFR level, instructions, optional lesson link and deadline.
- Students in that class see open assignments on `/student`.
- Students can open `/student/assignments/[assignmentId]`, follow the linked lesson and submit a written answer.
- Teacher can open the assignment from the class page, see submissions, score them 0–100 and leave written feedback.
- Reviewed score/feedback appears back on the student's assignment page.
- Finnish and Swedish class languages remain separated.
- Server-side checks verify teacher ownership, student class membership, account mode, language and deadline.
- Assignment mutations are server-only; RLS limits reads.
- Security audit events are written for assignment creation, submission and review.

## Database
Apply `supabase/migrations/20260914080000_teacher_assignments_feedback.sql` before testing with Supabase accounts.

## QA
Run `npm run audit:teacher-assignments` in addition to lint, typecheck and build.
