# V24.4.3 — Supabase Auth + teacher approval

Implemented on top of V24.4.2:

- auth callback now preserves a safe `next` path after email verification
- teacher signup verifies email then lands on `/teacher/application`
- pending/rejected teacher application status page
- teacher login detects pending applications and does not grant teacher access
- hidden `/admin/teachers` approval workspace, protected by server-side admin role check
- approval route promotes the profile and activates `teacher_access`
- rejection route records the decision without granting teacher role
- audit-log events for teacher approval/rejection
- migration hardens `teacher_applications` and re-asserts the auth-user trigger
- setup guide for Supabase keys, redirects, migrations and first-admin bootstrap

No client can self-promote to teacher or admin. The service-role key remains server-only.
