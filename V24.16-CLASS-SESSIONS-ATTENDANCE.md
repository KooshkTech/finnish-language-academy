# OpiOpe V24.16 — Calendar, live class sessions and attendance

This release adds teacher-scheduled class sessions and attendance tracking on top of V24.15.

## Added
- Teacher can schedule a live class session with start/end time, optional HTTPS meeting link and optional physical location.
- Students in the class receive an in-app notification when a session is scheduled.
- Teacher can mark a session completed, cancelled or scheduled again.
- Cancellation notifies class members.
- Teacher has a per-session attendance roster with present, late, absent and excused states.
- Students can see scheduled sessions, meeting links, and their own attendance status from the class page.
- Teacher calendar now combines live sessions with the existing content publication calendar.
- All session and attendance mutations verify teacher ownership server-side and write security audit events.

## Database
Apply `supabase/migrations/20260914150000_class_sessions_attendance.sql` before testing against Supabase.

## Important
The optional meeting URL links to an external meeting provider. V24.16 does not claim to provide built-in video conferencing.
