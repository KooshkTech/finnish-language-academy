# OpiOpe V17 — Level-First Simplification

## Goal
Simplify the first-time experience. The homepage now starts with CEFR levels A0–C2. Selecting a level opens that level's own home area and menu.

## New primary flow
Home → choose A0/A1/A2/B1/B2/C1/C2 → level home → choose skill → lesson → Blackboard → practice/flashcards/test.

## Level menu
Each level area contains:
- Kuuntelu / Listening
- Lukeminen / Reading
- Kirjoittaminen / Writing
- Ymmärtäminen / Grammar
- Sanasto / Vocabulary
- Puhuminen / Speaking
- YKI-testi practice

## UI simplification
The homepage no longer leads with all advanced platform tools. Dictionary, schedule and YKI remain accessible but are secondary. The selected level becomes the primary learning context.

## Classroom rule
Every level skill page uses the same four-step structure:
- Opi
- Harjoittele
- Flashcards
- Testi

A Blackboard is displayed alongside the lesson content, and the test is scoped to the lesson/module content.

## Truthfulness
YKI results remain practice-only and must not be represented as official YKI or CEFR certification.
