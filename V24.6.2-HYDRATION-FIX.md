# V24.6.2 Hydration Fix

Fixed the React/Next.js hydration warning caused by invalid HTML nesting in `InlineDictionaryText`.

## Problem
`InteractiveQALoop` renders `InlineDictionaryText` inside paragraph/strong contexts. The component itself rendered a `<div>` containing a `<p>`, which produced invalid structures such as `<p><div><p>...</p></div></p>` and triggered hydration errors.

## Fix
- Converted `InlineDictionaryText` to phrasing-safe inline markup (`span` + buttons).
- Converted the tooltip to inline-safe markup so the component can be safely rendered inside `<p>` and `<strong>`.
- Updated the related CSS selectors.
- Dictionary tooltip now shows the native-language definition (`definitionNative`) instead of the English definition.
- Added Finnish/Swedish localized dictionary-link and missing-entry text.
